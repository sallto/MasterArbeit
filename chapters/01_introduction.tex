\chapter{Introduction}\label{chapter:introduction}

\begin{itemize}
  \item Compile speed is important for some applications like Database systems
  \item For short running programs, compile time is the dominant factor
  \item Gains from optimizations are not sufficient to amortize the additional compile time
  \item For long running programs, runtime is the dominant factor and more expensive optimizations are beneficial
  \item For most scenarios where a short compile time is wanted, the most interesting metric is the combined compile and runtime of a program \todo{citation}
  \item TPDE~\cite{tpde} is currently the fastest Compiler for LLVM-IR in unoptimized scenarios (-O0) targeting x84-64 and AArch64
  \item However, transitioning from TPDE to the next optimization level, LLVM~\cite{llvm} O1 pipeline is a large step in compile time
  \item compile time increases by approximately \todo{10} times while delivering only around \todo{5} times runtime improvement (as illustrated in Fig.~\ref{fig:pareto_intro})
  \item Therefore there is a significant subset of programs in JIT scenarios that are likely to benefit from some level of optimization, but currently lack a fast enough solution
\end{itemize}
